# Handwritten Digit Recognition

This is a beginner-level Deep Learning project for recognizing handwritten digits.

## About the Project

This project uses the MNIST dataset of handwritten digits from 0 to 9.

A Deep Learning model is trained to recognize handwritten digits from input images.

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Google Colab

## Dataset

The MNIST dataset is used for training and testing the model.

## How It Works

1. Load the MNIST dataset.
2. Preprocess the images.
3. Build a Deep Learning model.
4. Train the model.
5. Test the model.
6. Predict handwritten digits.

## Result

The model can recognize handwritten digits from 0 to 9.

## How to Run

Open the Jupyter Notebook in Google Colab and run the cells from top to bottom.
